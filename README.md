# 🏋️ FitLog — Workout Library

FitLog is a modern and responsive workout library application built with **Next.js**. It allows users to explore different workouts, view detailed exercise information, create a daily workout plan, and save workouts for later.

## 🔗 Live Demo

**Live Site:https://fit-log-app-lac.vercel.app

## 📖 About the Project

FitLog is a dark-themed fitness application designed to make workout planning simple and organized.

Users can browse a collection of workouts, check exercise details, add exercises to today's workout plan, save workouts for later, and track total workout duration and calories.

## 🚀 Technologies Used

- Next.js
- React.js
- Tailwind CSS
- DaisyUI
- Context API
- Lucide React
- React Toastify
- JavaScript


## ✨ Key Features

### 1. Workout Library
Users can browse different workouts with useful information such as category, equipment, duration, calories, and rating.

### 2. Workout Details
Each workout has a dedicated details page containing exercise information, key specifications, instructions, and workout statistics.

### 3. Today's Workout Plan
Users can add exercises to **Today's Plan** and view their selected workouts from the My Plan page.

### 4. Save Workouts
Users can save workouts for later. The Saved tab keeps saved exercises separate from the daily workout plan.

### 5. Live Workout Statistics
The My Plan page automatically calculates and displays:

- Total Exercises
- Total Workout Minutes
- Total Calories

## ⭐ Additional Features

- Sort workouts by Duration, Calories, or Rating
- Mark workouts as completed
- Remove workouts from the plan
- Toast notifications for user actions
- Plan and Saved counters in the Navbar
- Loading animation while fetching workout data
- Custom 404 Not Found page
- Responsive design for mobile, tablet, and desktop
- Workout data persistence using LocalStorage

## 📱 Responsive Design

FitLog is fully responsive and optimized for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

## 🧭 Main Pages

- `/` — Workout Library / Home Page
- `/workouts/[id]` — Workout Details Page
- `/my-plan` — Today's Plan and Saved Workouts
- Custom 404 page for invalid routes
